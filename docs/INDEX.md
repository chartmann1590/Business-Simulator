## Quick Reference

### Setup & Installation
1. Read [README.md](../README.md) for prerequisites and setup
2. Follow PostgreSQL setup instructions
3. Configure Ollama and download Llama3.2 model
4. Run setup scripts

### Key Features
- **Autonomous Operation**: Office runs completely independently
- **AI-Powered Employees**: LLM-based decision making
- **Real-time Dashboard**: WebSocket-powered live updates
- **Multi-Floor Office**: 4 floors with specialized rooms
- **Home System**: Employee homes with families and pets
- **Comprehensive Tracking**: Sleep, clock in/out, sick days, breaks
- **Business Management**: Projects, tasks, financials, reviews
